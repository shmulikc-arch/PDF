# מילוי טפסי PDF

מעלים קובץ PDF, המערכת מזהה בו את מקומות המילוי (שורות, תיבות סימון, טבלאות, תאים ריקים ושדות טופס),
בונה מהם שאלון, ובסוף מפיקה את אותו PDF כשהוא מלא וחתום.

- הכול רץ בדפדפן. שום קובץ לא נשמר ולא נשלח לשרת.
- עובד על קבצים שנוצרו במחשב (Word, Google Docs וכו'). קובץ סרוק (תמונה) לא יזוהה.

## העלאה ל-GitHub Pages
1. יוצרים מאגר חדש ומעלים את כל הקבצים שבתיקייה הזו לשורש שלו.
2. Settings ← Pages ← Deploy from a branch ← main / root.

## קבצים
- `index.html`: המסך
- `app.js`: הלוגיקה של המסך
- `detect.js`: זיהוי מקומות המילוי בקובץ
- `fill.js`: כתיבת התשובות על ה-PDF
- `font.js`: גופן עברי (Liberation Sans) לכתיבת התשובות
- ספריות: pdf.js, pdf-lib, fontkit
